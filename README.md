## 📌 프로젝트 소개
여행을 준비하는 반려인 여러분, 이런 고민 많으셨죠?
- “우리 아이한테 맞는 숙소는 어디일까?” <br/>
→ 멍냥이랑은 등록된 반려동물의 성향과 활동량을 기반으로 맞춤형 숙소를 추천해드립니다.
- “필요한 조건에 맞는 숙소만 보고 싶어요!”  <br/>
→ 가격, 인원, 해시태그, 편의시설 등 다양한 필터 기능으로 원하는 숙소를 빠르게 찾을 수 있어요.
- “숙소에 궁금한 게 많은데 물어볼 데가 없네요…”  <br/>
→ 예약 전·후 언제든, 호스트와 1:1 채팅으로 문의할 수 있고, 답변이 오면 알림 기능으로 바로 확인할 수 있어요.
